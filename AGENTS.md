The project is a Minecraft mod, and is an addon to Mekanism mod. The Mekanism source code is in `mek` folder, and an overview can be found in `human` folder.

Do not try to build the files, instead just review and check them basically for a glance. A build, even just `javac`-ing the files, can take >1 hour in this environment due to bandwidth limit between WSL and Windows.
